# Flexible RSS for Yodeck

Flexible RSS is a full-screen HTML app for [Yodeck](https://www.yodeck.com/). It combines multiple RSS or Atom feeds in one display and rotates through their articles automatically.

The app supports feed images, article-page image fallbacks, a configurable header, publication dates, descriptions with automatic vertical scrolling, and QR codes linking to the original articles. It works with standard RSS and Atom feeds and includes optional parsing profiles for common publishing platforms.

## Features

- Multiple feeds in one app
- RSS 2.0 and Atom support
- Automatic or feed-order sorting
- Configurable rotation and refresh intervals
- Optional maximum article age per feed
- Images from RSS media elements, enclosures, HTML content, lazy-loading attributes, Open Graph metadata, or the linked article page
- Split, text-only, and full-image overlay layouts
- Full-screen, edge-to-edge presentation
- Configurable header title and colors
- Automatically scrolling descriptions when the available space is insufficient
- Optional publication date, article title, description, category, image, and QR code
- Automatic skipping of empty feeds
- No bundled feed URLs: administrators add only the sources they want to display

## Download

Do not download a source-code archive generated by GitHub. Instead, use one of these packages created by GitHub Actions:

- Stable/versioned build: open the repository's **Releases** page and download `flexible-rss-yodeck.zip` from the latest release.
- Development build: open **Actions**, select the latest successful **Build Yodeck package** run, and download the `flexible-rss-yodeck` artifact.

The ZIP contains `index.html`, `app.js`, and `style.css` directly at its root, as required by Yodeck. `schema.json` is supplied separately because its contents are pasted into Yodeck's UI Configuration field.

## Install in Yodeck

1. Download `flexible-rss-yodeck.zip` and `schema.json` from a GitHub Release.
2. Sign in to Yodeck and open **Apps**.
3. Open **My apps**, click **Create App**, and select **Create HTML app** under Custom Apps.
4. Enter an app name and optional description or icon.
5. Upload `flexible-rss-yodeck.zip` without extracting it.
6. Enable **Chromium**.
7. Open `schema.json` in a text editor, copy the complete JSON document, and paste it into Yodeck's **UI Configuration** field.
8. Keep the zoom factor at 100%. For an edge-to-edge layout, disable automatic zoom adjustment if it adds scaling on your target screen.
9. Save the custom app.
10. Create an instance of the app, configure its feeds and appearance, and add it to a playlist or screen layout.
11. Save and use **Push to Screens** so the player receives the new app and configuration.

Yodeck requires `index.html` at the root of the uploaded ZIP. The automated build packages it correctly. See the official [HTML App guide](https://www.yodeck.com/docs/user-manual/build-an-html-widget/) and [packaging requirements](https://www.yodeck.com/docs/user-manual/html-widget-packaging/) for details.

## Configuration

The most important settings in the generated Yodeck form are:

- **Display title**: the single header shown at the top of the app.
- **RSS feeds**: the list of enabled feed definitions.
- **RSS URL**: the RSS or Atom URL to load.
- **RSS format**: automatic detection, RWTH, WordPress, or standard RSS.
- **Maximum article age**: older articles are hidden; `0` disables the age limit.
- **Text source** and **image source**: automatic detection or an explicit source.
- **Optional CSS selectors**: advanced overrides for unusual feed or article markup.
- **Items per feed / total items**: limits for the rotation.
- **Display time**: number of seconds each article remains visible.
- **Refresh interval**: how often feeds are downloaded again.
- **Order**: mix all feeds by date or preserve feed order.
- **Layout**: split image/text, text only, or image overlay.
- **Image fit**: crop to fill the area or contain the complete image.

If a feed has no eligible articles, it is skipped. If all configured feeds are empty or unavailable, the app renders no slide.

## Local development and testing

Directly opening `index.html` is not sufficient because browsers commonly block cross-origin RSS requests. Use the included local proxy server instead:

```bash
python3 test_server.py
```

On Windows, depending on the Python installation, this may also work:

```powershell
py test_server.py
```

Then open:

```text
http://127.0.0.1:8080/?test=1
```

The server binds only to `127.0.0.1` and exposes a development-only `/proxy` endpoint. Stop it with `Ctrl+C`.

## Automated ZIP builds and releases

The workflow in `.github/workflows/build-release.yml` validates the configuration and creates the Yodeck ZIP automatically.

It uses GitHub's hosted `ubuntu-latest` runner. No always-on computer, local runner, or private build server is required. GitHub starts a temporary build machine for each workflow run and removes it afterward.

On every push and pull request:

1. The required runtime files are copied into a temporary package directory.
2. `flexible-rss-yodeck.zip` is created with `index.html` at the archive root.
3. The archive is checked for packaging errors.
4. The ZIP and `schema.json` are stored as a GitHub Actions artifact for 30 days.

To publish a permanent GitHub Release, push a version tag:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The workflow creates the matching Release and attaches both `flexible-rss-yodeck.zip` and `schema.json`. Generated ZIP files are never committed to the source repository.
